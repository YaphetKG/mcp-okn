OKN VoID graph descriptions (okn-void) is a meta-graph that describes the other graphs in the Proto-OKN federation rather than any subject domain. For each knowledge graph it records statistics in the VoID (Vocabulary of Interlinked Datasets) vocabulary and the VoID Extensions vocabulary: the total number of triples, distinct subjects, distinct objects and properties; a class partition giving each class's entity and triple counts; property partitions giving triple counts per property, both overall and within each class; and, for each class and property, the classes, datatypes and languages of the objects. Most graphs also carry provenance, a release version (pav:version) and a last-updated timestamp (pav:lastUpdatedOn). This server reads okn-void for get_kg_version and to build the per-KG schema files behind get_schema, comparing each graph's recorded triple count with the served graph to catch statistics that describe an older release. Query it to compare graph sizes, find which graphs use a given class or property, or check how current a graph is.
